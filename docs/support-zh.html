房况留证支持

用于入住、退租和普通检查的房况证据报告工具。

联系方式

邮箱：support@xufanzhilian.com

联系支持时，请附上设备型号、iOS 或 Android 版本、应用版本，以及问题的简要描述。

常见问题

  • 房况留证会上传我的照片吗？ 不会。MVP 版本会把照片和报告保存在你的设备本地。
  • 可以离线使用吗？ 可以。检查、签名、PDF 导出和 manifest 生成都采用本地优先设计。
  • 房况留证是法律建议吗？ 不是。房况留证用于整理证据记录，不提供法律建议。
  • 为什么需要位置权限？ 位置权限是可选的，仅在你希望证据记录包含大致位置元数据时使用。

数据和报告

生成的 PDF 和 JSON manifest 会保存在本地。通过系统分享面板发送文件时，目标位置由你自行选择。
