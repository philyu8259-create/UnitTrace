房况留证是一款面向租客、小房东和短租房东的本地房况证据工具，适合入住、退租、维修和日常巡检时整理可导出的房况记录。

核心流程：
- 创建房屋档案
- 开始入住检查、退租检查或普通检查
- 按房间拍照或添加文字备注
- 为每条证据保留时间、位置状态和 SHA-256 照片哈希
- 收集租客和房东签名
- 生成 PDF 证据报告和 JSON 证据清单
- 通过 iOS 系统分享导出文件

隐私优先：
- 不需要账号
- 房况留证不会上传照片
- 房屋、照片、签名、PDF 报告和 JSON manifest 默认保存在本机
- 相机、相册和位置权限只用于证据采集和可选元数据

房况留证是记录整理工具，不提供法律建议，也不保证纠纷结果。请在使用导出材料前自行核对报告内容、租赁文件和所在地规则。
